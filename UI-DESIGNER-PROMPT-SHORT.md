Help me redesign the UI for **Badge Journey**, a mobile-first Girl Scout badge app for a hackathon. Improve visuals and layout only — don’t invent new major features.

**Users:** kids ~5–17 + parent for signup. Warm, bright, playful, big tap targets (48px+). Readable for young kids with a 🔊 button; not babyish for teens.

**Tabs:** Home · Notebook · Journal (+ Gallery from Notebook/Journal)

**Flows to design for:**
1. **Onboarding** — language → name → grade/level → parent name/email → daisy bot-check → magic link → 3-card how-it-works
2. **Home** — badges for child’s level in category “clumps” (loose clusters, not a grid). Badges look colorful on Home.
3. **Badge Detail** — checklist; badge starts grey and fills with color as steps complete. “Tell us what you did” note must match the step. Finish all → celebrate → Make permanent (NFT, no keys shown to kids).
4. **Notebook** — free writing, optional title, multi-page/day, autosave, Gallery of past days
5. **Journal** — read-only earned/in-progress badges with expandable notes/dates/NFT link; Gallery by day for badge events

**Output please:**
1. Quick visual direction (colors, type, mood)
2. Simple wireframes for the 5 areas above
3. Empty/success/error states (esp. rejected notes)
4. Short polish checklist for Next.js + Tailwind in a hackathon

Keep it practical and shippable this weekend.
